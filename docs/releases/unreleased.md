# Open Model Gateway: unreleased

Notes for changes on `main` after [v0.16.0](v0.16.0.md). They become the next release's notes.

## Internal restructuring

For contributors; no gateway behaviour changes.

- **`Metrics::new` is split** (#537). The 510-line constructor now builds the families in `unregistered` and registers them in six helpers, in the same order: the same families, help text, buckets and pre-created series. The `#499` marker count drops by one.
- **`Engine::execute_protocol` is split** (#539). The inference entry point (386 lines by Clippy's count) keeps the request setup, routing plan and attempt loop; route eligibility, the all-refused error, per-attempt admission, the upstream call, the settlement of each outcome and the streamed-response tracker move into named helpers in `inference/attempt.rs`. The statements and their order are unchanged. `inference/mod.rs` drops from 1,208 to 875 production lines and the `#499` marker count by one.
- **Provider-cost `snapshot` is split** (#541). The 327-line comparison in `provider_costs/matching.rs` now runs as named steps (load the frozen observations, the personal workspace set, the imported actuals, the claims, the observation summary, the per-row binding match, the estimate-only rows and the category coverage), in the same order: the same SQL, report JSON and errors. The `#499` marker count drops by one.
- **`suggestion::map` is split** (#543). The OpenRouter catalog mapping (313 lines by Clippy's count) moves into `management/governance/suggestion/mapping.rs` and keeps the draft setup, the workload dispatch and the result; each workload's lines, the unmetered-price warnings, the request line, the draft price lines, `max_units` and the token ceilings become named helpers. The statements, warnings and their order are unchanged. `suggestion.rs` drops from 1,092 to 768 production lines and leaves the structure allowance list; the `#499` marker count drops by one.
- **The realtime session loop is split** (#545). `proxy` (284 lines by Clippy's count) keeps only the end-of-session dispatch (close code, outcome, error and finish label per ending), which the OpenAPI close-code test reads; the select loop, the client and upstream branches, the `response.create` refusal and reservation, the upstream stop and the closing handshake move into named steps over a small `Relay` state in `protocols/realtime/relay.rs`. The events, close frames, session calls, timeouts and their order are unchanged. `protocols/realtime.rs` drops from 1,126 to 812 production lines and the `#499` marker count by one.
- **`archive_in` is split** (#547). The one-transaction partition archive in `archive.rs` (about 280 lines by Clippy's count) now runs as named steps (locate the partitions, begin and lock with the already-archived and attached checks, the retention check, the legal-hold check, the history checks and sums, the export, the manifest, the records and the detach), in the same order: the same SQL, refusals, export files, manifest and report. `archive.rs` grows from 596 to 711 production lines; the `#499` marker count drops by one.
- **Batch planning's `scan` is split** (#549). The batch input scan (273 lines by Clippy's count) keeps the read loop, the line count limit and the issue cut-off; each line's checks (shape and `custom_id`, the memoised model resolution and price preview, native and engine support, the adapter's deterministic refusal), the grouping, the work-file copy and the whole-file checks become named steps over a small `ScanState`, the per-line ones in `jobs/plan/scan.rs`. The checks, issues, lookups and their order are unchanged. The `#499` marker count drops by one.
- **Messages `Request::normalize` is split** (#551). The Anthropic Messages request conversion in `protocols/messages/request.rs` (261 lines by Clippy's count) now runs as named steps (the sampling and option bounds, the metadata label, the native message envelopes, the system prompt, each wire message and content block, `tool_use`, `tool_result`, each tool and `tool_choice`), in the same order: the same `ChatRequest`, refusals and error precedence. The `#499` marker count drops by one.
- **Bedrock's `encode` is split** (#553). The Converse request builder in `providers/bedrock.rs` (about 220 lines by Clippy's count) now runs as named steps (the request bounds, the tool specs, the tool choice, the tool configuration, then each message through a small `Turns` state: system blocks, tool results, text and tool calls, the tool-result merge, and the final turn checks with the inference configuration), in the same order: the same Converse input, errors and check precedence. `bedrock.rs` grows from 662 to 763 lines; the `#499` marker count drops by one.
