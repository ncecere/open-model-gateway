# Open Model Gateway v0.2.0

v0.2.0 (tag `v0.2.0`, commit `faef11c`, 2026-10-09) adds alerts, key safety, SCIM, metrics and backup tooling for operators, async video and batch jobs, realtime audio, and budget admission that no longer slows down as history grows. It covers commits `4dc3faf`, `f67ec85` and `faef11c` after [v0.1.0](v0.1.0.md).

## Highlights

- **Alerts** ([alerts](../alerts.md)): budget thresholds, spend spikes, error rates and failing connections for the installation and for Team and Project workspaces; owner-only personal budget alerts. A background evaluator, in-app notifications with a top-bar bell, and email through the SMTP settings. Unknown cost is flagged, never counted as zero.
- **Key safety** ([key safety](../key-safety.md)): findings such as no expiry, no budget, holder left, over the maximum lifetime, stale secret, unused and broad access, with one-click fixes. Personal keys appear to platform staff only as counts.
- **Model compare:** two to four models side by side, with exact price lines, ceilings, readiness and 30 days of scoped telemetry.
- **SCIM 2.0** ([SCIM](../scim.md)): Users and Groups with group-provenance grants, suspension on deactivation, and revoked keys that never return.
- **OIDC signing keys:** a bounded JWKS cache with a single refetch on an unknown key id ([identity](../identity.md#signing-keys-jwks)).
- **Operations** ([operations](../operations.md)): Prometheus metrics on a separate listener, structured readiness checks, `scripts/backup.py` with checksummed manifests and lineage-checked restores, a Grafana dashboard and alert rules.
- **Budget admission in constant time:** trigger-maintained budget totals per scope and period. With 200k reservations in a month, mixed traffic went from 19 to 124 req/s and budget-bound traffic from 20 to 150 req/s in the load test. `open-model-gateway budget verify` checks the totals against a full scan.
- **Pool exhaustion fixed:** at 200 concurrent requests on a 10-connection pool, admission and settlement now queue in process instead of starving authentication.
- **Async jobs** ([async jobs](../async-jobs.md)): `/v1/videos` (OpenAI `sora-*`, priced per second) and `/v1/files` plus `/v1/batches` for Chat Completions lines on OpenAI, with bodies streamed and never stored, and a background poller.
- **Realtime audio** ([realtime](../realtime.md)): a `/v1/realtime` WebSocket proxy for the OpenAI GA interface, with an event allowlist, per-response reservations and settlement, and session, idle, size and rate caps.
- **Telemetry:** the provider-reported upstream model and Anthropic thinking tokens.
- **Tests:** a Playwright browser suite with per-persona journeys and axe accessibility scans in CI, and a reproducible load-test harness against a mock upstream.

## New environment variables

| Variable | Default | Purpose |
|---|---|---|
| `GATEWAY_ALERT_INTERVAL_SECONDS` | `60` | Alert evaluator interval; `0` turns it off |
| `GATEWAY_METRICS_ADDR` | unset | Separate Prometheus listener; keep it on loopback or a private network |
| `GATEWAY_DATABASE_MAX_CONNECTIONS` | `10` | Database pool size per replica |
| `GATEWAY_SCIM_TOKEN_ENV` | unset | Name of the variable that holds the SCIM bearer token; enables SCIM |
| `GATEWAY_JOB_POLL_INTERVAL_SECONDS` | `30` | Async job poller interval |
| `GATEWAY_MAX_BODY_BYTES_VIDEOS` | 2 MiB | `POST /v1/videos` body cap |
| `GATEWAY_MAX_BATCH_FILE_BYTES`, `GATEWAY_BATCH_MAX_OUTPUT_SCAN_BYTES` | 200 MiB, 1 GiB | Batch input and output scan caps |
| `GATEWAY_REALTIME_*` | see [realtime](../realtime.md) | Session length, idle time, message size, event rate and output token caps |

## Behaviour changes

- Workspace and Admin headers collapse to the primary action and a "…" menu on phones; accounting meters show Unknown instead of `$0.00` when cost is unknown.
- The runtime role has no DELETE on alert tables, and its grants cover the new tables. Reapply `runtime-grants.sql` after migrating (below).

## Upgrading from v0.1.0

1. Take a backup with `scripts/backup.py` and check it ([operations](../operations.md)).
2. Stop the gateway: mixed-schema replicas are not supported.
3. Run `open-model-gateway migrate` as the migrator. Nothing migrates on `serve`.
4. Reapply `deploy/staging/runtime-grants.sql` for the runtime role. `python3 scripts/staging.py migrate` does steps 3 and 4.
5. Run `open-model-gateway budget verify`: `0015` backfills the totals from history, and the command must report no mismatches.
6. Start v0.2.0 and wait for `/health/ready`.

## Known limitations

- Development software: not accepted for production.
- Video, batches and realtime audio are mock-tested only; no live or paid video, batch or realtime request was made for this release.
- JWKS refresh and SCIM have not been exercised against a real identity provider.
- Only OpenAI runs video and batches; OpenRouter returns `unsupported_capability`.
- The binary still reports `0.1.0`: the version was not bumped before tagging. From v0.3.0 the release workflow refuses a tag that doesn't match the binary.

## Verifying the images

No container image was published for v0.2.0: signed release images start with [v0.3.0](v0.3.0.md#verifying-the-images). Build v0.2.0 from its tag with the repository's `Dockerfile` if you need it.
