# Open Model Gateway v0.6.1

A security patch for every outbound TLS connection. Upgrade from v0.6.0 by replacing the image: there are no migrations, no configuration changes and no API changes.

## Security

- **TLS: distrusted emSign intermediates** (RUSTSEC-2026-0381, RUSTSEC-2026-0382, published 2026-10-21). `webpki-roots` 1.0.9 → 1.0.10 and `rustls-webpki` 0.103.15 → 0.103.16. The bundled roots no longer include `emSign ECC Root CA - G3`, and certificate paths through the distrusted emSign intermediates, whose private keys are public, are rejected. Before this fix, someone able to intercept the gateway's network traffic could have impersonated an upstream with such a certificate. Affected: every outbound TLS connection (providers, OIDC, S3, SMTP, the realtime WebSocket, audit export).

## Upgrade

No migrations (the schema is unchanged since v0.6.0). Roll the image: Helm `image.tag: v0.6.1` with `image.digest` pinned to the verified digest below, or the container image by digest. `grants apply` is not needed but harmless.

## Known limitations

Unchanged from [v0.6.0](v0.6.0.md#known-limitations).

## Verifying the images

The image is `ghcr.io/ncecere/open-model-gateway`, tagged `v0.6.1`, `v0.6` and `latest-release`. Deploy by digest: the digest is in the GitHub Release, its `open-model-gateway-v0.6.1.digest.txt` asset, and the workflow's job summary.

Verify the signature with [cosign](https://docs.sigstore.dev/cosign/system_config/installation/) **v3.0 or newer** (keyless, GitHub Actions OIDC). The signature is stored in cosign v3's bundle format, so cosign v2 reports "no signatures found":

```sh
cosign verify ghcr.io/ncecere/open-model-gateway@sha256:<digest> \
  --certificate-identity https://github.com/ncecere/open-model-gateway/.github/workflows/image.yml@refs/tags/v0.6.1 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

The signature covers the multi-arch index, and so every tag that points at it. The SBOM (SPDX) and build provenance are attached to the image as attestations:

```sh
docker buildx imagetools inspect ghcr.io/ncecere/open-model-gateway@sha256:<digest> --format '{{ json .SBOM }}'
docker buildx imagetools inspect ghcr.io/ncecere/open-model-gateway@sha256:<digest> --format '{{ json .Provenance }}'
```

The Release also carries each platform's SBOM as `open-model-gateway-v0.6.1-linux-<arch>.sbom.spdx.json`, with `checksums.txt` (`sha256sum -c checksums.txt`). The Helm chart (`deploy/helm/open-model-gateway/`, chart version 0.6.1) defaults `image.tag` to `v0.6.1`; pin `image.digest` to the verified digest before a real rollout.
