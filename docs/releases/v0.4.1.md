# Open Model Gateway v0.4.1

A focused dashboard fix for [#18](https://github.com/ncecere/open-model-gateway/issues/18).

## Add-model validation

- Required pricing ceilings are clearly marked, with a linked validation summary.
- Invalid submission scrolls to and focuses the first invalid field, including fields below the fold.
- Text and System One output-ceiling errors consistently require a positive value.
- Browser regressions cover invalid and corrected submission at desktop and phone widths.

No database migration, inference protocol, provider, pagination or deployment behavior changes are included. The Helm chart's beta status is unchanged; its version and default application tag follow this release.
